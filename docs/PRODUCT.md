# Product: Personal Work History (작업 기록)

## Goal

A local-first Windows desktop app that turns raw computer activity into an
**editable, searchable work history** for an individual software developer.

It answers:

- What did I work on today?
- What was I doing in project X yesterday?
- When did I last work on a specific task?
- What should I resume when I return to a project?
- What did I accomplish this week?

It is **not** a screen recorder, an app-usage dashboard, or an AI chatbot.

**Direction (2026-10-01):** work is increasingly done with AI and, in
폐쇄망 environments, carried in by USB, so the primary record is **results**:
changes to files in the user's work folders, snapshotted into hidden local
Git repositories (see RESULTS_TRACKING.md). Window activity is a secondary
signal. AI (a local model on the PC; nothing needs the internet) turns the record into
reports and answers, citing the exact changes, sessions and notes it used.
Plain activity trackers already show app usage; this product's value is
the layer on top: projects, work sessions, notes, AI reports and search.

## Primary user

One developer on Windows 10/11, Korean UI, working offline-first.

## MVP scope

| Area | MVP behaviour |
|---|---|
| Collection | Window (app + title), browser address without query string, and idle periods, read by the app itself (Windows). No keystrokes, clipboard, screenshots, OCR, or document contents. |
| Projects | User-created projects; keyword rules on app name / window title; manual override per activity and per session. No LLM. |
| Work sessions | Deterministic grouping of activity into sessions; editable title, project, notes; merge, split, exclude. Labeled as *inferred*. |
| Daily timeline | Per-app view (default: one entry per app with its time added up over the day, window titles added up inside, most recently used first) or session view (newest first): time range, app, duration, session, file changes; filters for date and app. No project or note panels (2026-11-05). |
| Reports | AI 업무일지 / 주간보고 drafts citing the records they use; editable, saved. |
| Search | Local search over session titles, project names, app/window titles, notes, changed files; date and project filters. "AI에게 묻기" answers questions such as where a project was left, with citations. |
| Settings | Projects, keyword rules, user-written next action per project, work folders, launch, AI model, privacy. |
| Privacy | Pause/resume, exclusion list, data deletion, localhost-only server. |

## Non-goals

Accounts, cloud sync, team features, subscriptions, browsing history,
OCR/screenshots, mobile, multi-device merge.

## Honesty rules for the UI

- Sessions and report drafts generated by the app are **inferred** from window
  metadata and are labeled as such ("자동 추정").
- The app never claims what the user accomplished or what to do next unless the
  user wrote it.
- Demo/sample data lives in a separate database and is always bannered.
