      작업 폴더 결과물 기록
      
          
        
      
        
      등록한 폴더의 파일 변경을 5분마다 별도의 숨은 Git 저장소에 기록합니다. 폴더 안의 파일과 원래 Git 저장소는 읽기만 하고 바꾸지 않습니다. 비밀 파일(.env, *.pem, *.key 등)과 빌드 결과물·5MB 넘는 파일은 기록하지 않습니다.
      
        
        
        
        
          
          
          
          
        
        
      
        
      
        
        
        
        
      
        
      
        규칙: 앱 이름이나 창 제목에 키워드가 포함되면 해당 프로젝트로 자동 분류합니다 (대소문자 무시, 가장 긴 키워드 우선). 타임라인에서 직접 지정한 프로젝트가 규칙보다 우선합니다.
        
      
        
    
        

    
    
        
      
        
        
        AI 설정
        
        
        
        
        
          
          
        
        
        
        이 PC에 설치·로그인된 Claude Code로 보고서와 'AI에게 묻기'를 처리합니다. API 키가 필요 없고, 사용량은 Claude 계정에 포함됩니다. 켜기 전에는 실제 업무 기록을 AI에 보내지 않습니다 (데모 데이터는 가능). 켜면 업무 기록이 비밀값을 가린 뒤 Claude Code를 거쳐 Anthropic으로 전송되고, 이때 Claude Code는 파일·명령·웹 도구 없이 이 앱의 읽기 전용 기록 도구만 쓸 수 있습니다. '연결 확인'은 업무 기록을 보내지 않고 설치·로그인 상태만 확인합니다.
        
        
        
      
        
      
        
        
        Claude Code 연결 MCP
        
        
        
        
        
        켜면 이 앱이 Claude Code에 자동으로 연결됩니다. Claude Code에서 "지난주 GOV-1418 어디까지 했지?"처럼 물으면 Claude가 이 기록을 읽기 전용으로 찾아봅니다. 찾은 내용은 Claude Code를 통해 Anthropic으로 전송됩니다 (비밀값은 가려서 보냄, 업무 앱만 기록·제외 목록 그대로 적용). 끄면 연결도 자동으로 해제됩니다.
