    AI 초안은 기록에 근거한 추정입니다. 사실과 다른 내용은 고친 뒤 저장하세요. "(근거 없음)" 표시는 꼭 확인하세요. 차주 계획·다음 할 일은 직접 씁니다.
                한 일은 모두 "(진행 중)"으로 시작합니다. 끝낸 일은 저장한 뒤 보고서 화면에서 눌러 "완료"로 바꾸거나, 여기서 "(완료)"로 고치면 됩니다.
    
            
    
          
    
        
    
        
    
      
    
    
    

    
    
    
      
    
        
    AI에게 묻기 AI
    
        
    
          
          
        
    
        
    
        
    AI가 내 기록을 직접 찾아보고 근거와 함께 답합니다. 근거를 누르면 해당 기록으로 이동합니다. 확인되지 않은 근거는 표시하지 않습니다.
    
      
    
      
    
        
        
        
        
        
      
    
      
    
    
    

    
    
    
      
    
        
    
          
    작업 폴더 결과물 기록
    
          
        
    
        
    등록한 폴더의 파일 변경을 5분마다 별도의 숨은 Git 저장소에 기록합니다. 폴더 안의 파일과 원래 Git 저장소는 읽기만 하고 바꾸지 않습니다. 비밀 파일(.env, *.pem, *.key 등)과 빌드 결과물·5MB 넘는 파일은 기록하지 않습니다.

      AI 설정
      
        
      
        
      
          
          
        
      
        
      내 PC 모델은 앱 폴더의 llm 폴더에 있는 AI를 이 PC에서 직접 돌립니다. 기록이 PC 밖으로 나가지 않고 인터넷이 없어도 되지만, 그래픽카드가 없으면 느립니다.
      
        
      Claude Code 모델은 이 PC에 설치·로그인된 Claude Code로 보고서와 'AI에게 묻기'를 처리합니다. API 키가 필요 없고, 사용량은 Claude 계정에 포함됩니다. 켜기 전에는 실제 업무 기록을 AI에 보내지 않습니다 (데모 데이터는 가능). 켜면 업무 기록이 비밀값을 가린 뒤 Claude Code를 거쳐 Anthropic으로 전송되고, 이때 Claude Code는 파일·명령·웹 도구 없이 이 앱의 읽기 전용 기록 도구만 쓸 수 있습니다. '연결 확인'은 업무 기록을 보내지 않고 설치·로그인 상태만 확인합니다.
