# 작업 기록 앱 시연 시나리오 (실제 기록)

_마지막 갱신: 2026-11-05 · 발표 자료: 같은 폴더의 `작업 기록 앱-(대인배)-v2.pptx`_

## 개요

발표와 시연을 합쳐 **15분**입니다(질문 제외). 슬라이드 1\~11번을 6분 동안 발표하고, 슬라이드 12번에서 앱으로 넘어가 8분 시연한 뒤, 슬라이드 12번으로 돌아와 질문을 받습니다. 시연은 데모 데이터 없이, 발표자 PC에 쌓인 **실제 기록**만으로 합니다.

| 순서 | 내용 | 시간 | 누적 |
| --- | --- | --- | --- |
| 발표 | 슬라이드 1\~11번 | 6분 | 6:00 |
| 전환 | 슬라이드 12번에서 앱으로 | 15초 | 6:15 |
| 장면 1 · 기록 | 고른 하루의 타임라인, 고친 파일의 바뀐 줄 | 1분 | 7:15 |
| 장면 2 · 실시간 기록 | 지금 파일을 고치면 바로 기록되는 것 | 1분 30초 | 8:45 |
| 장면 3 · 이어서 하기 | 프로젝트별 마지막 작업과 다음 할 일 | 40초 | 9:25 |
| 장면 4 · 주간보고 | 미리 만든 AI 초안, 출처를 눌러 기록으로 가 보기 | 1분 30초 | 10:55 |
| 장면 5 · 비밀값 가리기 | AI에 보낼 내용에서 비밀번호가 \*\*\*로 바뀜 | 40초 | 11:35 |
| 장면 6 · 물어보기 | 기록에 있는 질문, 없는 질문 | 1분 | 12:35 |
| 장면 7 · 기록 통제 | 일시정지, 기록 대상, 제외, 삭제 | 1분 | 13:35 |
| 마무리 | 슬라이드 12번으로 돌아가 한 줄 정리 | 20초 | 13:55 |
| 여유 | 클릭 실수, 화면 전환 | 1분 | 14:55 |

- **발표 6분:** 발표자 노트를 그대로 읽되, 1분에 250음절 정도로 천천히 읽으면 6분이 됩니다.
- **실제 기록이 화면에 나옵니다.** 창 제목, 파일 이름, 메모가 청중에게 보입니다. 발표 전날까지 사전 준비 1의 "화면에 나올 기록 점검"을 꼭 끝냅니다.
- **AI 결과는 미리 만들어 둡니다.** 주간보고 초안과 물어보기 답을 발표 전에 받아 브라우저 탭에 펼쳐 둡니다. CPU만 있는 PC에서 주간보고 한 편이 6\~10분 걸리기 때문입니다.
- 슬라이드 6\~8번의 화면(장면 1, 4, 6)에 슬라이드에 없던 네 가지(장면 2, 3, 5, 7)를 더했습니다. 슬라이드 11번(원칙)에서 말로 한 약속을 장면 5와 7에서 눈으로 보여 줍니다.
- 시간이 모자랄 때 빼는 순서: 장면 3 → 장면 7 → 장면 1. 장면 2, 4, 6은 끝까지 남깁니다.

## 사전 준비

1\~2는 **발표 전날**, 3\~6은 **당일 시작 30분 전**에 합니다. 발표자 PC에는 앱이 적어도 1\~2주 기록해 둔 상태여야 합니다.

### 1. 화면에 나올 기록 점검 (전날)

시연 화면에는 실제 창 제목, 파일 이름, 메모가 그대로 나옵니다. 아래 화면을 발표 때와 같은 순서로 열어 보고, 남에게 보이면 안 되는 것을 지웁니다.

| 화면 | 보이는 것 | 확인할 것 |
| --- | --- | --- |
| 타임라인 (장면 1에 쓸 날) | 세션의 창 제목, 고친 파일 이름과 바뀐 줄, 메모 | 메신저 대화 상대·내용, 개인 사이트, 사람·고객 이름, 내부 시스템 주소 |
| 이어서 하기 | 프로젝트 이름, 다음 할 일, 마지막으로 본 창 | 마지막으로 본 창의 제목 |
| 보고서 초안과 출처 | 한 주의 업무 요약 | 밖에 말하기 곤란한 업무 내용 |
| 물어보기 답 | 답과 출처 | 위와 같음 |
| 보낼 내용 보기 | 오늘 기록 전체 | 위와 같음. 길어서 다 보여 주지 않고 Ctrl+F로 바로 이동함 |
| 개인정보 탭 | 기록 대상·제외 목록의 앱 이름과 키워드 | 키워드 자체가 민감하지 않은지 |

지우는 방법:

- 세션 하나: 타임라인에서 그 세션의 **제외**를 누릅니다.
- 앞으로 안 나오게: 개인정보 탭 → **제외 목록**에 앱이나 창 제목 키워드를 넣습니다.
- 기간 통째로: 개인정보 탭 → **데이터 삭제**에서 기간을 골라 지웁니다. 되돌릴 수 없습니다.
- 장면 1에 쓸 날은 고친 파일이 2\~3개 이상 있고 민감한 창이 없는 날로 고릅니다.

### 2. AI 켜기와 질문 고르기 (전날)

1. 개인정보 탭 → **AI 설정**에서 내 PC 모델(9B 추천)을 고릅니다. 고르기 전에는 AI가 꺼져 있습니다.
2. 물어보기 질문 두 개를 정합니다.
    - 기록에 있는 일: 실제로 한 일을 이슈 번호나 작업 이름으로 묻습니다. 예: "지난주 ○○ 작업 어디까지 했지?"
    - 기록에 없는 일: 한 적 없는 일을 묻습니다. 예: "AI 기본법 대응 작업은 어디까지 했지?"(슬라이드 8번과 같은 질문)
3. 두 질문을 한 번씩 돌려 보고, 답의 내용과 걸린 시간을 적어 둡니다. 장면 6의 대사는 이 답에 맞춰 고칩니다.

### 3. 시연용 작업 폴더 등록 (장면 2용, 당일)

실제 작업 파일을 고치면 그 변경이 업무 기록에 섞입니다. 그래서 시연만을 위한 폴더를 잠깐 등록했다가 발표 후 지웁니다.

1. `C:\시연\sample-project` 폴더를 만들고, 그 안에 `greet.py`를 만들어 두 줄을 적습니다: `def greet(name):` / `    return "hello " + name`
2. **프로젝트** 탭 → 작업 폴더에 `C:\시연\sample-project`를 넣고 **폴더 추가** → **지금 기록**을 누릅니다. "파일 1개"가 보이면 준비 끝입니다.
3. 메모장으로 `greet.py`를 열어 둡니다.

### 4. 비밀번호 메모 넣기 (장면 5용, 당일)

타임라인에서 **오늘** 버튼을 누른 뒤, 메모에 지어낸 비밀번호가 들어간 문장을 적고 저장합니다. 예: `시연용 메모. password=Qa2026!secret`. 진짜 비밀번호는 쓰지 않습니다.

### 5. 브라우저 탭 5개 준비 (당일 30분 전)

앱 주소(기본 `http://127.0.0.1:5730/`, 개인정보 탭에 표시)를 탭 5개로 열고 아래처럼 펼쳐 둡니다. **AI 작업은 하나씩 차례로** 돌립니다. 장면 2, 3, 7은 탭 1에서 메뉴만 바꿔 진행합니다.

| 탭 | 화면 | 미리 해 둘 일 | 걸리는 시간 |
| --- | --- | --- | --- |
| 1 | 타임라인 | 날짜를 장면 1에 쓸 날로 맞춤 | 즉시 |
| 2 | 보고서 | 주간보고 → 보여 줄 주(기록이 많은 주) → **AI 초안 만들기** | CPU만: 6\~10분, 그래픽카드: 3\~4분 |
| 3 | 검색 | AI에게 묻기에 기록에 있는 질문 | 2에서 잰 시간 |
| 4 | 검색 | AI에게 묻기에 기록에 없는 질문 | 2에서 잰 시간 |
| 5 | 보고서 | **업무일지**를 고르고 날짜는 오늘로 둠 (누르는 것은 발표 때) | 즉시 |
| 메모장 | `greet.py` | 3에서 열어 둔 창 | — |

주의할 것:

- 보고서 초안은 **저장을 누르지 마세요.** 저장하면 본문은 남지만, 다시 열 때 오른쪽 출처 칸이 비어 나옵니다.
- 어느 탭도 **새로 고침(F5)하지 마세요.** 초안과 답이 화면에서 사라집니다.
- 탭 안에서 다른 메뉴로 갔다 와도 초안과 출처는 그대로 있습니다.

### 6. 화면과 발표 환경

- 브라우저 확대를 125\~150%로 올리고(Ctrl + +), F11 전체 화면으로 둡니다.
- 발표자 보기를 쓰면, 브라우저 창을 미리 **청중이 보는 화면** 쪽으로 옮겨 둡니다. 화상회의라면 화면 전체를 공유해야 브라우저로 넘어갔을 때도 보입니다.
- 메신저, 메일 등 다른 창을 닫고 Windows의 방해 금지 모드를 켭니다. 앱은 발표 중에도 창을 기록하므로, 열어 둔 창이 장면 2의 세션으로 화면에 나옵니다.
- 노트북은 전원을 연결합니다. AI가 도는 동안 배터리가 빨리 닳고 느려집니다.

## 장면 1 · 기록 (1분 15초, 탭 1)

슬라이드 12번에서 앱으로 넘어가, 발표자의 실제 하루가 자동으로 정리되고 고친 파일이 기록된 것을 보여 줍니다(전환 15초 포함).

| 순서 | 할 일 | 할 말 |
| --- | --- | --- |
| 1 | 슬라이드 12번 "감사합니다"에서 질문을 받기 전에 멈춤 | "질문 받기 전에, 실제 앱으로 몇 가지 더 보여 드리겠습니다. 제 PC에 실제로 쌓인 기록입니다." |
| 2 | Alt+Tab으로 브라우저 탭 1을 띄움 | "제 하루가 작업 단위로 자동으로 묶여 있습니다. 제가 따로 적은 건 메모뿐입니다." |
| 3 | 위쪽 **프로젝트별 활동 시간**을 가리킴 | "프로젝트별로 몇 시간을 썼는지 자동으로 집계됩니다." |
| 4 | '자동 추정' 표시가 붙은 세션 하나를 가리킴 (바꾸지 않음) | "앱이 짐작한 것은 '자동 추정'으로 표시되고, 틀리면 제목과 프로젝트를 바로 고칠 수 있습니다." |
| 5 | 오른쪽 **결과물 변경**에서 미리 고른 파일 하나를 누름 | "이날 실제로 고친 파일입니다." |
| 6 | 창에 뜨는 빨간 줄과 초록 줄을 가리킴 | "무엇을 바꿨는지 그대로 남습니다. 빨간 줄은 지운 내용, 초록 줄은 새로 쓴 내용입니다." |
| 7 | **닫기**를 누름 | "이건 지난 기록이고요, 지금 이 자리에서 기록되는 걸 보여 드리겠습니다." |

- 5번에서 누를 파일은 전날 점검할 때 고릅니다. 바뀐 줄이 짧고 알아보기 쉬운 파일이 좋습니다.
- 기록 대상을 골라 두었다면 3번에서 "기록 대상이 아닌 창은 제목 없이 '업무 외'로만 남습니다"를 덧붙입니다.
- 실제 기록이라 세션을 고치거나 병합하지 않고 가리키기만 합니다.

## 장면 2 · 실시간 기록 (1분 30초, 탭 1 + 메모장)

방금 고친 파일이 바로 기록되는 것을 눈앞에서 보여 줍니다. 사전 준비 3의 시연용 폴더를 씁니다.

| 순서 | 할 일 | 할 말 |
| --- | --- | --- |
| 1 | Alt+Tab으로 메모장을 띄움 | "시연용 폴더를 하나 등록해 두었습니다. 지금 이 파일에 두 줄을 더해서 저장하겠습니다." |
| 2 | `return` 줄 위에 두 줄을 넣고 Ctrl+S: `    if not name:` / `        return "hello, guest"` | (말 없이 입력) |
| 3 | 탭 1로 돌아와 **프로젝트** 메뉴 → **지금 기록**을 누름 | "앱은 5분마다 알아서 폴더를 살피는데, 지금은 바로 기록하겠습니다." |
| 4 | **타임라인** 메뉴 → **오늘** → 오른쪽 결과물 변경의 `greet.py (+2 −0)`를 누름 | "방금 더한 두 줄이 초록색으로 기록됐습니다. 원래 파일은 읽기만 하고, 변경 기록은 따로 숨은 저장소에 남습니다." |
| 5 | **닫기** → 위쪽 **지금 동기화** 버튼을 누름 | "창 기록도 마찬가지입니다. 방금까지 발표하던 PowerPoint와 메모장이 작업 세션으로 잡혔습니다." |

- 5번에서 세션이 아직 안 보이면 "창 기록은 1분마다 모입니다"라고 하고 넘어갑니다.
- 메모장에서 들여쓰기를 맞추기 어렵다면 두 줄을 클립보드에 담아 두고 Ctrl+V로 넣습니다.

## 장면 3 · 이어서 하기 (40초, 탭 1)

"어제 어디까지 했지?"에 AI 없이도 바로 답하는 화면입니다.

| 순서 | 할 일 | 할 말 |
| --- | --- | --- |
| 1 | 위쪽 **이어서 하기** 메뉴를 누름 | "아침에 앱을 열면 제일 먼저 보는 화면입니다." |
| 2 | 왼쪽 프로젝트 목록을 가리킴 | "프로젝트마다 마지막으로 작업한 때와 최근 7일 작업 시간, 제가 적어 둔 다음 할 일이 나옵니다." |
| 3 | 오른쪽 "마지막으로 본 창"을 가리킴 | "마지막에 보던 창까지 나오니, 바로 이어서 시작할 수 있습니다." |

- 마지막으로 본 창은 발표 중에 연 창(PowerPoint 등)일 수 있습니다. 그러면 "방금 발표하던 화면까지 나옵니다"라고 말합니다.
- 프로젝트에 다음 할 일을 적어 둔 적이 없다면, 전날 한 프로젝트에 실제 다음 할 일을 적어 둡니다.

## 장면 4 · 주간보고 (1분 30초, 탭 2)

발표 전에 실제 기록으로 만들어 둔 주간보고 초안을 보여 주고, 슬라이드에는 없던 "출처를 눌러 기록으로 가 보기"를 합니다.

| 순서 | 할 일 | 할 말 |
| --- | --- | --- |
| 1 | Ctrl+2로 탭 2로 옮김 | "버튼 한 번으로 만든 제 주간보고 초안입니다. CPU만 있는 PC에서 몇 분 걸려서, 발표 전에 이 PC의 AI로 만들어 두었습니다." |
| 2 | 왼쪽 초안을 위에서 아래로 천천히 훑음 | "프로젝트별로 한 일, 다음 주 계획, 이슈가 정리됩니다. 제가 쓴 건 메모 몇 줄뿐입니다." |

- 4번에서 누를 출처는 초안을 만든 뒤 미리 골라 둡니다. 누르면 어느 화면으로 가는지도 확인합니다.

## 장면 7 · 기록 통제 (1분 20초, 탭 1)

슬라이드 11번의 "감시가 아니라 나를 위한 기록"을 설정 화면으로 보여 주고, 발표를 마무리합니다(마무리 20초 포함).

## 비상 대처

장면 하나에서 문제가 생기면 그 장면만 건너뛰고 다음 장면으로 갑니다. 앱 자체가 안 되면 슬라이드 12번으로 돌아가 질문을 받고, 남는 시간은 질문으로 채웁니다. 같은 화면을 슬라이드 6\~8번에서 이미 보여 줬기 때문에 발표 내용은 빠지지 않습니다.

| 상황 | 대처 |
| --- | --- |
| 앱이 열리지 않거나 화면 공유가 안 됨 | 시연을 건너뛰고 "앞의 슬라이드 6\~8번이 실제 앱 화면입니다"라고 말한 뒤 질문을 받음 |
| 보여 주면 안 되는 기록이 화면에 뜸 | 당황하지 말고 바로 다음 탭으로 넘어감. 발표 후 그 세션을 제외하거나 기간 삭제함 |
| 장면 2에서 지금 기록을 눌렀는데 변경이 안 보임 | 메모장에서 저장(Ctrl+S)했는지 보고 한 번 더 누름. 그래도 안 되면 장면 1의 기록을 가리키며 "5분마다 이렇게 남습니다"라고 하고 넘어감 |
| 탭을 새로 고쳐 초안이나 답이 사라짐 | 그 장면만 건너뜀, 다시 만들지 않음 |
| 발표 전에 AI 초안이 끝내 안 나옴 | 장면 4를 빼고, 그 시간은 질문으로 채움 |
| 출처를 눌렀는데 엉뚱한 화면이 나옴 | 위쪽 **보고서** 메뉴로 돌아와 다음 장면으로 넘어감 |
| 보낼 내용에서 메모가 안 보임 | 탭 5의 날짜가 오늘인지 확인. 없으면 슬라이드 11번 설명으로 대신함 |
| AI 답이 전날과 다름 | 화면에 나온 답을 그대로 설명하고, 출처가 붙어 있다는 점만 강조함 |
| 시간이 모자람 | 장면 3 → 7 → 1 순서로 뺌. 장면 2, 4, 6은 남김 |
| 시간이 남음 | 질문을 일찍 받음. 시연을 늘리지 않음 |
| 시연 중에 질문이 나옴 | "시연 끝나고 바로 답하겠습니다"라고 하고 이어 감 |

리허설은 적어도 한 번, 발표할 PC에서 실제로 해 봅니다. 리허설에서 고친 기록(메모, 시연용 폴더)도 아래 순서로 정리합니다.
