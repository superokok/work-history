# 작업 기록 앱 시연 시나리오와 대본

_마지막 갱신: 2026-11-05 · 발표 자료: 같은 폴더의 발표 파일(.pptx) · 앱 0.1.1 기준(탭: 타임라인 · 보고서 · 검색 · 설정)_

이 문서는 두 부분입니다. **1부 시나리오**는 준비와 장면별로 누를 것, **2부 대본**은 시연 중에 할 말입니다.

# 1부 · 시나리오

## 개요

발표와 시연을 합쳐 **15분**입니다(질문 제외). 슬라이드 1–11번을 6분 동안 발표하고, 슬라이드 12번에서 앱으로 넘어가 8분 시연한 뒤, 슬라이드 12번으로 돌아와 질문을 받습니다.

시연은 데모 모드(`--demo`)가 아니라 **평소 쓰는 앱과 DB**에서 합니다. 지난 기록은 그 DB에 미리 넣어 둔 **테스트 데이터**이고, 장면 2(실시간 기록)만 발표장에서 실제로 기록합니다. 데모 모드가 아니라 화면 위에 "데모 데이터" 띠가 나오지 않으므로, 대본에서 시연용 기록이라고 말로 밝힙니다.

| 순서 | 내용 | 시간 | 누적 |
| --- | --- | --- | --- |
| 발표 | 슬라이드 1–11번 | 6분 | 6:00 |
| 장면 1 · 기록 | 전환, 고른 하루의 앱별 타임라인, 창 경로, 고친 파일의 바뀐 줄 | 1분 15초 | 7:15 |
| 장면 2 · 실시간 기록 | 지금 파일을 고치면 바로 기록되는 것 | 1분 30초 | 8:45 |
| 장면 3 · 검색 | AI 없이 지난 기록 찾기 | 40초 | 9:25 |
| 장면 4 · 주간보고 | 미리 만든 AI 초안, 출처를 눌러 기록으로 가 보기 | 1분 30초 | 10:55 |
| 장면 5 · 비밀값 가리기 | AI에 보낼 내용에서 비밀번호가 \*\*\*로 바뀜 | 40초 | 11:35 |
| 장면 6 · 물어보기 | 기록에 있는 질문, 없는 질문 | 1분 | 12:35 |
| 장면 7 · 기록 통제와 마무리 | 일시정지, 기록 대상, 제외, AI 설정, 삭제, 한 줄 정리 | 1분 20초 | 13:55 |
| 여유 | 클릭 실수, 화면 전환 | 1분 | 14:55 |

- **발표 6분:** 발표자 노트를 1분에 250음절 정도로 천천히 읽으면 6분이 됩니다.
- **테스트 데이터만 화면에 나오게 합니다.** 같은 DB에 평소 기록이 있으면 시연할 날짜·주에 섞여 나올 수 있습니다. 발표 전날까지 사전 준비 1을 꼭 끝냅니다.
- **AI 결과는 미리 만들어 둡니다.** 주간보고 초안과 물어보기 답을 발표 전에 받아 브라우저 탭에 펼쳐 둡니다. Claude로는 10초 안팎이면 나오지만, 발표장 네트워크나 로그인 문제로 시연이 멈추지 않게 하기 위해서입니다.
- 슬라이드 6–8번의 화면(장면 1, 4, 6)에 슬라이드에 없던 네 가지(장면 2, 3, 5, 7)를 더했습니다. 슬라이드 11번(원칙)에서 말로 한 약속을 장면 5와 7에서 눈으로 보여 줍니다.
- 시간이 모자랄 때 빼는 순서: 장면 3 → 장면 7(마무리 대사만 남김) → 장면 1. 장면 2, 4, 6은 끝까지 남깁니다.

## 사전 준비

1–2는 **발표 전날**, 3–5는 **당일 시작 30분 전**에 합니다. 평소 쓰는 DB에 테스트 데이터(1–2주 분량의 지어낸 창 기록·작업 세션·메모, `seed-demo.cmd`)를 넣어 둔 상태에서 시작합니다. 테스트 데이터에는 작업 폴더가 없으므로, 파일 변경은 설정 탭에서 추가한 폴더(사전 준비 3)에서 나옵니다.

### 1. 테스트 데이터 점검 (전날)

아래 화면을 발표 때와 같은 순서로 열어 보고, 테스트 데이터가 제대로 보이는지, 평소 기록이 섞여 나오지 않는지 확인합니다.

| 화면 | 확인할 것 |
| --- | --- |
| 타임라인 앱별 (장면 1에 쓸 날) | 앱 카드와 창 제목이 테스트 데이터대로 나옴. 평소 기록(메신저, 메일, 개인 사이트)이 섞이지 않음 |
| 창을 눌렀을 때 나오는 경로 | 장면 1에서 누를 창에 경로나 주소가 나옴. 경로가 없는 창도 있으므로 나오는 창을 미리 골라 둠 |
| 결과물 변경에서 파일을 누름 | 추가한 작업 폴더의 파일을 누르면 바뀐 줄(빨간 줄·초록 줄)이 나옴 |
| 타임라인 오늘 (장면 2) | 발표 당일 아침부터 쓴 창(평소 기록)이 나옴. 당일 아침에 연 메신저·메일이 없는지 |
| 검색 결과 (장면 3) | 검색어로 테스트 데이터의 세션이 나오고, 추가한 폴더의 변경 파일도 나옴 |
| 보고서 (장면 4에 쓸 주) | 그 주에 테스트 데이터만 있음 |
| 설정 탭 | 작업 폴더 경로, 기록 대상·제외 목록의 이름과 키워드가 보여도 되는 것인지 |

평소 기록이 섞여 나오면:

- 세션 하나: 타임라인에서 **세션별** 보기로 바꾸고, 그 세션의 **제외**를 누릅니다.
- 앞으로 안 나오게: 설정 탭 → **제외 목록**에 앱이나 창 제목 키워드를 넣습니다.
- 기간 통째로: 설정 탭 → **데이터 삭제**에서 기간을 골라 지웁니다. 되돌릴 수 없으므로, 테스트 데이터를 넣기 전에 DB를 따로 복사해 두는 것이 안전합니다.
- 장면 1에 쓸 날은 고친 파일이 2–3개 이상 있는 날로 고릅니다.

### 2. AI 켜기와 질문 고르기 (전날)

1. 설정 탭 → **AI 설정**에서 Claude 모델을 고르고 **연결 확인**을 누릅니다. 고르기 전에는 AI가 꺼져 있습니다.
    - 이 PC에 Claude Code가 설치되어 있고 로그인된 상태여야 합니다. 목록에 Claude가 없거나 연결 확인이 실패하면, 리허설 전에 해결합니다.
    - Claude에는 보고서 기간의 기록이 가려진 뒤 전송됩니다. 그 기간에 테스트 데이터만 있는지 1에서 확인합니다.
2. 물어보기 질문 두 개를 정합니다.
    - 기록에 있는 일: 테스트 데이터에 들어 있는 일을 이슈 번호나 작업 이름으로 묻습니다. 예: "지난주 ○○ 작업 어디까지 했지?"
    - 기록에 없는 일: 테스트 데이터에 없는 일을 묻습니다. 예: "AI 기본법 대응 작업은 어디까지 했지?"(슬라이드 8번과 같은 질문)
3. 두 질문을 한 번씩 돌려 보고 답을 적어 둡니다. 2부 대본 장면 6의 ○○ 부분은 이 답에 맞춰 채웁니다.
4. 장면 3의 검색어를 하나 정합니다. 테스트 데이터에 여러 번 나오는 이슈 번호나 파일 이름이 좋습니다.

### 3. 시연용 작업 폴더 등록 (장면 2·5용, 당일)

실제 작업 파일을 고치면 그 변경이 업무 기록에 섞입니다. 그래서 시연만을 위한 폴더를 잠깐 등록했다가 발표 후 지웁니다.

1. `C:\시연\sample-project` 폴더를 만들고, 그 안에 `greet.py`를 만들어 두 줄을 적습니다: `def greet(name):` / `    return "hello " + name`
2. 설정 탭 → **작업 폴더**에 `C:\시연\sample-project`를 넣고 **폴더 추가** → **지금 기록**을 누릅니다.
3. 같은 폴더에 `config.py`를 만들고 지어낸 비밀번호 한 줄을 적어 저장합니다: `DB_PASSWORD = "Qa2026!secret"`. 진짜 비밀번호는 쓰지 않습니다.
4. 다시 **지금 기록**을 누르고, 타임라인 **오늘**의 결과물 변경에 `config.py`가 보이는지 확인합니다. 장면 5에서 이 변경을 씁니다.
5. 메모장으로 `greet.py`를 열어 둡니다.

### 4. 브라우저 탭 5개 준비 (당일 30분 전)

앱 주소(기본 `http://127.0.0.1:5730/`, 설정 탭 → 실행에 표시)를 탭 5개로 열고 아래처럼 펼쳐 둡니다. **AI 작업은 하나씩 차례로** 돌립니다. 장면 2, 3, 7은 탭 1에서 메뉴만 바꿔 진행합니다.

| 탭 | 화면 | 미리 해 둘 일 |
| --- | --- | --- |
| 1 | 타임라인 | 날짜를 장면 1에 쓸 날로 맞춤. 보기는 **앱별** |
| 2 | 보고서 | **주간보고** → 보여 줄 주(기록이 많은 주) → **AI 초안 만들기** |
| 3 | 검색 | **AI에게 묻기**에 기록에 있는 질문 → **묻기** |
| 4 | 검색 | **AI에게 묻기**에 기록에 없는 질문 → **묻기** |
| 5 | 보고서 | **업무일지**를 고르고 날짜는 오늘로 둠 (보낼 내용 보기는 발표 때 누름) |
| 메모장 | `greet.py` | 3에서 열어 둔 창 |

주의할 것:

- 보고서 초안은 **저장을 누르지 마세요.** 저장하면 본문은 남지만, 다시 열 때 오른쪽 출처 칸이 비어 나옵니다.
- 어느 탭도 **새로 고침(F5)하지 마세요.** 초안과 답이 화면에서 사라집니다.
- 탭 안에서 다른 메뉴로 갔다 와도 초안과 출처는 그대로 있습니다.

### 5. 화면과 발표 환경

- 브라우저 확대를 125–150%로 올리고(Ctrl + +), F11 전체 화면으로 둡니다.
- 발표자 보기를 쓰면, 브라우저 창을 미리 **청중이 보는 화면** 쪽으로 옮겨 둡니다. 화상회의라면 화면 전체를 공유해야 브라우저로 넘어갔을 때도 보입니다.
- 메신저, 메일 등 다른 창을 닫고 Windows의 방해 금지 모드를 켭니다. 앱은 발표 중에도 창을 기록하므로, 열어 둔 창이 장면 2의 오늘 타임라인에 나옵니다.
- 노트북은 전원을 연결합니다.

## 장면별 동작

### 장면 1 · 기록 (1분 15초, 탭 1)

1. 슬라이드 12번 "감사합니다"에서 질문을 받기 전에 멈춤
2. Alt+Tab으로 브라우저 탭 1을 띄움
3. 앱 카드 하나를 가리킴: 앱마다 하루 쓴 시간을 합치고, 창 제목별 시간이 안에 나옴
4. 미리 고른 창 줄 하나를 누름 → 나오는 경로(파일 경로나 웹 주소)를 가리킴
5. 오른쪽 **결과물 변경**에서 미리 고른 파일 하나를 누름 → 빨간 줄과 초록 줄을 가리킴
6. **닫기**

- 5번에서 누를 파일은 바뀐 줄이 짧고 알아보기 쉬운 것으로 전날 고릅니다.
- 시간을 아끼려고 세션을 고치거나 병합하지 않고 가리키기만 합니다.

### 장면 2 · 실시간 기록 (1분 30초, 탭 1 + 메모장)

1. Alt+Tab으로 메모장을 띄움
2. `return` 줄 위에 두 줄을 넣고 Ctrl+S: `    if not name:` / `        return "hello, guest"`
3. 탭 1로 돌아와 **설정** 메뉴 → 작업 폴더의 **지금 기록**을 누름
4. **타임라인** 메뉴 → **오늘** → 오른쪽 결과물 변경의 `greet.py (+2 −0)`를 누름 → 초록 두 줄을 가리킴
5. **닫기** → 위쪽 **지금 동기화** → 앱 카드에 PowerPoint와 메모장이 잡힌 것을 가리킴

- 5번에서 아직 안 보이면 "창 기록은 1분마다 모입니다"라고 하고 넘어갑니다.
- 메모장에서 들여쓰기를 맞추기 어렵다면 두 줄을 클립보드에 담아 두고 Ctrl+V로 넣습니다.

### 장면 3 · 검색 (40초, 탭 1)

1. **검색** 메뉴 → 전날 정한 검색어를 넣고 **검색**
2. 결과의 **작업 세션**과 **변경 파일** 묶음을 가리킴
3. 결과 하나의 날짜를 누름 → 그날 타임라인으로 옮겨진 것을 가리킴

- 탭 3, 4에는 AI 답이 펼쳐져 있으므로, 검색은 꼭 탭 1에서 합니다.

### 장면 4 · 주간보고 (1분 30초, 탭 2)

1. Ctrl+2로 탭 2로 옮김
2. 왼쪽 초안을 위에서 아래로 천천히 훑음 → 업무 묶음 이름(이슈 번호, 저장소) 하나를 가리킴
3. "(근거 없음)", "(AI 제안 — 확인 필요)", "(완료 근거 없음 — 확인 필요)" 표시가 있으면 가리킴
4. 오른쪽 출처 칸에서 주황색(고친 파일) 출처 하나를 누름 → 열린 변경 내용을 가리킴
5. 위쪽 **보고서** 메뉴를 눌러 초안으로 돌아옴

- 4번에서 누를 출처는 초안을 만든 뒤 미리 골라 두고, 누르면 어느 화면으로 가는지도 확인합니다.
- 3번의 표시가 하나도 없으면 다음 계획 줄의 "AI 제안"만 가리킵니다.

### 장면 5 · 비밀값 가리기 (40초, 탭 5)

1. Ctrl+5로 탭 5로 옮김
2. **보낼 내용 보기**를 누름
3. 곧바로 Ctrl+F로 `DB_PASSWORD`를 찾아 `"***"` 부분을 가리킴

- 보낼 내용에는 오늘 기록이 통째로 나옵니다. 스크롤하며 보여 주지 말고 2번 다음 바로 Ctrl+F로 이동합니다.

### 장면 6 · 물어보기 (1분, 탭 3과 4)

1. Ctrl+3으로 탭 3 → 답과 출처를 따라 가리킴, 답 아래 "확인한 기록: 기록 검색 → 하루 보기…" 줄을 가리킴
2. Ctrl+4로 탭 4 → "찾지 못했습니다" 답을 가리킴

### 장면 7 · 기록 통제와 마무리 (1분 20초, 탭 1)

1. Ctrl+1로 탭 1 → 위쪽 **일시정지** 버튼을 가리킴 (누르지 않음)
2. **설정** 메뉴 → **기록 대상**을 가리킴
3. **제외 목록**을 가리킴
4. **AI 설정**을 가리킴

## 비상 대처

장면 하나에서 문제가 생기면 그 장면만 건너뛰고 다음 장면으로 갑니다. 앱 자체가 안 되면 슬라이드 12번으로 돌아가 질문을 받고, 남는 시간은 질문으로 채웁니다. 같은 화면을 슬라이드 6–8번에서 이미 보여 줬기 때문에 발표 내용은 빠지지 않습니다.

| 상황 | 대처 |
| --- | --- |
| 앱이 열리지 않거나 화면 공유가 안 됨 | 시연을 건너뛰고 "앞의 슬라이드 6–8번이 실제 앱 화면입니다"라고 말한 뒤 질문을 받음 |
| 평소 기록(보여 주면 안 되는 것)이 화면에 뜸 | 당황하지 말고 바로 다음 장면으로 넘어감. 발표 후 그 세션을 제외하거나 기간 삭제함 |
| 장면 2에서 지금 기록을 눌렀는데 변경이 안 보임 | 메모장에서 저장(Ctrl+S)했는지 보고 한 번 더 누름. 그래도 안 되면 장면 1의 기록을 가리키며 "5분마다 이렇게 남습니다"라고 하고 넘어감 |
| 탭을 새로 고쳐 초안이나 답이 사라짐 | **AI 초안 만들기**나 **묻기**를 다시 누름(Claude로 10초 안팎). 30초 안에 안 나오면 그 장면을 건너뜀 |
| 발표 전에 AI 초안이 끝내 안 나옴 | 연결 확인으로 Claude 로그인 상태를 봄. 안 되면 장면 4·6을 빼고 그 시간은 질문으로 채움 |
| 출처를 눌렀는데 엉뚱한 화면이 나옴 | 위쪽 **보고서** 메뉴로 돌아와 다음 장면으로 넘어감 |
| 보낼 내용에서 `DB_PASSWORD`가 안 보임 | 탭 5의 날짜가 오늘인지 확인. 없으면 슬라이드 11번 설명으로 대신함 |
| AI 답이 전날과 다름 | 화면에 나온 답을 그대로 설명하고, 출처가 붙어 있다는 점만 강조함 |
| 시간이 모자람 | 장면 3 → 7(마무리 대사만) → 1 순서로 뺌. 장면 2, 4, 6은 남김 |
| 시간이 남음 | 질문을 일찍 받음. 시연을 늘리지 않음 |
| 시연 중에 질문이 나옴 | "시연 끝나고 바로 답하겠습니다"라고 하고 이어 감 |

리허설은 적어도 한 번, 발표할 PC에서 실제로 해 봅니다. 리허설에서 고친 기록(시연용 폴더)도 아래 순서로 정리합니다.

# 2부 · 대본

[ ] 안은 동작, 나머지는 할 말입니다. ○○는 전날 확인한 테스트 데이터의 내용으로 채웁니다. 지난 기록은 시연용으로 넣은 것이라고 처음에 한 번 밝히고, 장면 2에서 실제로 기록되는 것을 보여 줍니다.

### 장면 1 · 기록 (1분 15초)

[슬라이드 12번에서 멈춤]
질문 받기 전에, 실제 앱으로 몇 가지 더 보여 드리겠습니다. 제가 평소에 쓰는 앱에, 시연을 위해 개발자 한 명의 2주 치 작업 기록을 넣어 두었습니다.

[Alt+Tab → 탭 1]
하루가 앱별로 정리되어 있습니다. 평소에는 따로 적을 것 없이 앱이 이렇게 알아서 기록합니다. 앱마다 하루 몇 시간 썼는지, 그 안에서 어떤 창을 얼마나 봤는지 나옵니다.

[창 줄 하나를 누름]
창을 누르면 그때 보던 파일 경로나 웹 주소가 나오고, 바로 복사할 수 있습니다. "그 문서 어디 있었지?"를 찾을 필요가 없습니다.

[결과물 변경의 파일 하나를 누름]
그리고 이게 핵심입니다. 이날 실제로 고친 파일입니다. 빨간 줄은 지운 내용, 초록 줄은 새로 쓴 내용입니다. 무엇을 바꿨는지 그대로 남습니다.

[닫기]
이건 넣어 둔 지난 기록이고요, 이번엔 지금 이 자리에서 실제로 기록되는 걸 보여 드리겠습니다.

### 장면 2 · 실시간 기록 (1분 30초)

[Alt+Tab → 메모장]
시연용 폴더를 하나 작업 폴더로 등록해 두었습니다. 지금 이 파일에 두 줄을 더해서 저장하겠습니다.

[두 줄 입력, Ctrl+S — 말 없이]

[탭 1 → 설정 → 지금 기록]
앱은 5분마다 알아서 폴더를 살피는데, 지금은 바로 기록하겠습니다.

[타임라인 → 오늘 → greet.py (+2 −0)]
방금 더한 두 줄이 초록색으로 기록됐습니다. 원래 파일은 읽기만 하고, 변경 기록은 따로 숨은 저장소에 남습니다. Git을 몰라도, 커밋을 안 해도 됩니다.

[닫기 → 지금 동기화]
창 기록도 마찬가지입니다. 방금까지 발표하던 PowerPoint와 메모장이 오늘 기록에 잡혔습니다.

### 장면 3 · 검색 (40초)

[검색 메뉴 → 검색어 입력 → 검색]
"그거 언제 했지?"는 AI 없이도 찾을 수 있습니다. ○○로 찾아보면, 그 이름이 들어간 작업 세션과 고친 파일이 날짜와 함께 한 번에 나옵니다.

[결과 하나의 날짜를 누름]
날짜를 누르면 그날 기록으로 바로 갑니다. ○월 ○일에 마지막으로 작업했다는 걸 바로 알 수 있습니다.

### 장면 4 · 주간보고 (1분 30초)

[Ctrl+2 → 탭 2]
이 기록으로 버튼 한 번에 만든 지난주 주간보고 초안입니다. Claude가 썼고, 10초 정도 걸립니다. 발표 시간을 아끼려고 미리 만들어 두었습니다.

[초안을 훑으며 업무 묶음 하나를 가리킴]
프로젝트를 따로 나눠 두지 않았는데도, AI가 이슈 번호와 저장소를 보고 ○○, ○○처럼 일을 알아서 묶었습니다. 업무마다 한 일, 다음 계획, 이슈가 정리됩니다.

[표시가 붙은 문장을 가리킴]
다음 계획은 기록에 없는 내용이라 'AI 제안'으로 표시됩니다. 출처가 없거나 '완료'를 확인할 수 없는 문장에도 표시가 붙어서, 제가 확인하고 고칩니다.

[오른쪽 출처 칸의 주황색 출처를 누름]
문장에 붙은 출처를 눌러 보겠습니다. AI가 쓴 문장이 실제로 이 파일 변경에서 나왔다는 걸 바로 확인할 수 있습니다. 출처가 기록에 없으면 프로그램이 지웁니다.

[보고서 메뉴로 돌아옴]
초안은 그대로 남아 있고, 고치거나 복사해서 보고에 쓰면 됩니다. 기억으로 15분에서 20분 걸리던 주간보고가 검토 5분으로 줄었습니다.

### 장면 5 · 비밀값 가리기 (40초)

[Ctrl+5 → 탭 5]
제가 오늘 작업하다가 설정 파일에 비밀번호를 적어 버렸다고 해 보겠습니다. 미리 넣어 둔 가짜 비밀번호입니다.

[보낼 내용 보기]
AI 초안을 만들기 전에, AI에 무엇을 보내는지 그대로 볼 수 있습니다. 여기 나온 것 외에는 아무것도 보내지 않습니다.

[Ctrl+F → DB_PASSWORD → "***"를 가리킴]
파일에는 비밀번호가 그대로 있지만, AI에 가는 내용에서는 별표로 가려져 있습니다. 인증키, 토큰, 주민번호도 마찬가지입니다.

### 장면 6 · 물어보기 (1분)

[Ctrl+3 → 탭 3]
"○○"라고 물었습니다. AI가 앱의 읽기 전용 도구로 기록을 직접 찾아보고 답했습니다. ○○ — 답의 흐름을 한 문장으로. 문장마다 출처가 붙고, 아래에는 AI가 어떤 기록을 확인했는지까지 나옵니다.

[Ctrl+4 → 탭 4]
기록에 없는 일을 물으면 어떻게 될까요? "AI 기본법 대응 작업은 어디까지 했지?" 지어내지 않고, 기록에서 찾지 못했다고 답합니다. 그럴듯한 거짓말보다 '모른다'가 낫습니다.

### 장면 7 · 기록 통제와 마무리 (1분 20초)

[Ctrl+1 → 일시정지 버튼을 가리킴]
마지막으로, 기록은 제가 통제합니다. 회의나 개인 용무 때는 이 버튼 하나로 멈춥니다.

[설정 → 기록 대상]
어떤 프로그램을 기록할지 제가 고릅니다. 고르지 않은 창은 이름도 제목도 없이 '업무 외' 시간으로만 남습니다.

[제외 목록]
특정 프로그램이나 창 제목은 아예 기록하지 않게 할 수 있습니다.

[AI 설정]
AI는 제가 모델을 직접 골라야 켜지고, '사용 안 함'으로 언제든 끕니다. 인터넷이 없는 PC에서는 내 PC에서 도는 AI로 바꿀 수 있습니다.

[데이터 삭제]
기록은 모두 이 PC 안에만 있고, 기간을 골라 언제든 지울 수 있습니다. 회사로 보내는 기능은 아예 없습니다.

[Alt+Tab → 슬라이드 12번]
지난 기록은 시연용으로 넣은 것이고, 방금 고친 파일과 발표 화면은 이 자리에서 실제로 기록된 것입니다. 기록은 이 PC에만 있고, AI에는 가린 내용만 보냅니다. 기억 말고 기록으로 보고합니다. 질문 받겠습니다.
